# Projet Javascript - JEU & SITE

Ce projet a été réalisé dans le cadre de notre formation. il regroupe une application de jeu interactive ainsi qu'un site web dédié, le tout développé principalement en JavaScript.

## 📝 Description du projet
L'objectif de ce projet est de mettre en pratique les concepts fondamentaux et avancés du développement Web et de la programmation JavaScript. Il se divise en deux parties majeures :
* **JEU** : Toute la partie C pour la réalisation de niveaux entièrement aléatoires.
* **SITE** : Une interface vitrine/interactive permettant de naviguer dans l'univers du projet, de son jeu et ses niveaux de 1 à 10.

## 🚀 Fonctionnalités principales
* **Partie Jeu** :
    * Mécaniques de jeu dynamiques (mouvements, scores, etc.).
    * Gestion des événements clavier/souris.
    * Bouger son personnage pour que le personnage miroir bouge aussi, et les faire parvenir, tous les deux à la sortie.
    * Music, sons, transitions, fondus etc... Tout a été fait en javascript.
* **Partie Site** :
    * Navigation fluide entre les différentes sections.
    * Design responsive pour s'adapter à différents écrans.
    * Intégration d'éléments interactifs.

## 🛠️ Installation et Exécution
Pour lancer le projet localement, suivez ces étapes :

1. **Installer MAMP** :
https://www.mamp.info/en/downloads/

2. **Cloner le dépôt dans C:/MAMP/htdocs** :
   ```bash
   git clone https://github.com/Badis-Junia/Projet_Javascript.git
   ```

3. Si pas déjà fait, se rendre sur http://localhost/phpMyAdmin5/ et y ajouter la base de donnée qui sera nommée : "blockmirrordata" et y importer alors la base de donnée qui se trouvera dans SITE/basededonnees/blockmirrordata.sql

4. **Lancer MAMP et bien faire attention que *ApacheServer* ainsi que *MySQLServer* soient cochés** 

5. **Se rendre dans http://localhost/PROJET/SITE/index.html pour pouvoir avoir accès au Site. Se créer un compte puis pouvoir jouer !**
